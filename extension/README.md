# 12dPL Debugger

Step-through debugging for 12d Model macros (12dPL): breakpoints, stepping,
call stack and variables.

Access via the "Compile/Debug" 4do. To get it, run **12dPL: Build Companion
Macro** from the Command Palette: it compiles the macro with 12d's `cc4d.exe`
(set `12dpl.compilerPath` if 12d is installed elsewhere) and shows the `4do`
in Explorer.
